# سیستم ثبت و چاپ سند کارپردازی

برنامه فارسی تحت شبکه برای ثبت فاکتور/سند کارپرداز با چاپ یک‌صفحه‌ای A4 (مطابق نمونه سند هزینه شعبه)،
مدیریت تنخواه، کاربران و سطوح دسترسی، لاگ تغییرات و بکاپ خودکار.

## امکانات
- ثبت سند با حداکثر **۱۵ ردیف** (تاریخ، شرح هزینه، بیمه، مالیات، مبلغ به ریال) + جمع خودکار
- شماره‌گذاری خودکار: `کدشعبه(دو رقمی)-سال-عدد متوالی` → مثال `45-1405-0007`
  (با شروع سال جدید، عدد متوالی هر شعبه از ۱ ریست می‌شود)
- چاپ دقیقاً **یک صفحه A4**: سربرگ + لوگو، جدول اقلام، ۴ بخش چک (درخواست صدور چک تنخواه /
  بررسی امور مالی / دستور صدور چک / صدور و تحویل چک)، فوتر اسناد، و **جعبه تنخواه
  (تاریخ آخرین واریز + مانده تنخواه + جای امضا) در پایین سمت راست**
- روند **پیش‌نویس ← نهایی‌کردن** توسط کارپرداز + **ابطال** سند با دلیل (فقط مدیر/سرپرست)
- تنخواه: ثبت واریزها، کارتکس هر شعبه، مانده = مجموع دریافتی‌ها − مجموع کل اسناد نهایی
- کاربران با ۴ نقش (مدیر سیستم، سرپرست/مالی، کارپرداز، ناظر) و رابطه **چند-به-چند** کارپرداز ↔ شعبه
- لاگ کامل تغییرات + بکاپ خودکار روزانه + بکاپ دستی قابل دانلود
- تنظیمات چاپ: لوگو، نام شرکت/مجتمع، ش ملی، کد اقتصادی، متن استاندارد، قالب شماره سند

## پیش‌نیاز
- Python 3.10 یا جدیدتر

## نصب و اجرا

### ✅ ساده‌ترین روش (ویندوز) — بدون تایپ هیچ دستوری
کافی است فایل **`START.bat`** را **دوبار کلیک** کنید.
این فایل همه‌چیز را خودکار انجام می‌دهد:
1. پایتون را پیدا می‌کند (اگر نباشد، خودکار با `winget` نصب می‌کند)
2. محیط مجازی می‌سازد
3. پیش‌نیازها را نصب می‌کند
4. برنامه را اجرا می‌کند و مرورگر باز می‌شود

> اگر Python نصب نبود و نصب خودکار هم جواب نداد، یک‌بار Python را از
> [python.org](https://www.python.org/downloads/) نصب کنید (حتماً تیک **Add python.exe to PATH** را بزنید)
> و دوباره `START.bat` را اجرا کنید.

### Windows (PowerShell) — روش دستی
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

### Linux یا macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

### استفاده چند نفره روی شبکه داخلی
روی یک کامپیوتر مورد اعتماد:
```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```
بقیه کاربران از مرورگر به `http://IP-میزبان:8501` وصل می‌شوند.
(پورت ۸۵۰۱ را فقط برای شبکه داخلی در فایروال باز کنید؛ به اینترنت forward نکنید.)

## راه‌اندازی اولیه (فقط یک بار)
1. **ساخت حساب مدیر:** در نخستین اجرا، فرم ساخت حساب مدیر باز می‌شود.
2. **تعریف شعب:** ⚙️ مدیریت ← 🏢 شعب ← کد **دو رقمی** + نام شعبه (مثال: 45 — شهید کاوه)
3. **تنظیمات چاپ:** ⚙️ مدیریت ← 🖨 تنظیمات چاپ ← لوگو، نام شرکت، کد اقتصادی و …
4. **تعریف کاربران:** ⚙️ مدیریت ← 👥 کاربران ← نقش + شعبه‌های قابل دسترسی
5. **تنخواه:** 💰 تنخواه ← ثبت واریزهای تنخواه هر شعبه
6. **ثبت سند:** 📄 اسناد ← ➕ سند جدید ← ذخیره پیش‌نویس ← نهایی‌کردن ← چاپ

## چاپ
در صفحه «مشاهده/چاپ» هر سند:
- دکمه **🖨 چاپ** یا **⬇ دانلود فایل چاپی (HTML)** و سپس بازکردن فایل در مرورگر + `Ctrl+P`
- خروجی دقیقاً **یک صفحه A4** است؛ اگر محتوایی بیش از حد باشد برنامه **هشدار** می‌دهد.

## داده‌ها و پشتیبان
- پایگاه داده: `instance/senad.db` (فایل محلی — آن را روی NAS اشتراکی قرار ندهید)
- پشتیبان خودکار: هر روز یک‌بار هنگام ورود، در `instance/backups/` (۳۰ نسخه اخیر نگه داشته می‌شود)
- پشتیبان دستی: ⚙️ مدیریت ← 💾 بکاپ (قابل دانلود)
- مسیر دلخواه دیتابیس: متغیر محیطی `SENAD_DB_PATH`

## ساختار فایل‌ها
```
app.py                نقطه ورود
senad_app/
  config.py           تنظیمات و مجوزها
  db.py               ساختار پایگاه داده (SQLite)
  auth.py             کاربران و احراز هویت (هش PBKDF2)
  services.py         منطق: اسناد، شماره‌گذاری، تنخواه، لاگ، بکاپ
  printing.py         صفحه چاپی یک‌صفحه‌ای A4
  ui*.py              رابط کاربری فارسی
tests/test_senad.py   آزمون‌های منطق اصلی
docs/                 اسناد تحلیل نیازمندی‌ها و نمونه چاپ
```

## امنیت
- گذرواژه‌ها با PBKDF2-HMAC-SHA256 (200k تکرار) هش می‌شوند.
- هر تغییر مهم (ثبت/ویرایش/نهایی/ابطال/کاربران/تنظیمات) در لاگ ثبت می‌شود.
- توصیه: رمزنگاری دیسک میزبان (BitLocker/LUKS) و محدودکردن دسترسی پوشه `instance`.
